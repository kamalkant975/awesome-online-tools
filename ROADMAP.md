# Roadmap

This roadmap tracks both the tool count on [OnlineToolkitHub](https://www.onlinetoolkithub.com) and the structure of this list, since the two grow together.

## Platform Milestones

- [x] ✅ **200+ Tools** — live across PDF, Image, AI, Developer, SEO, Calculator, Text, and Utility categories
- [ ] 🚀 **300 Tools** — expanded AI and Utility categories, deeper PDF editing features
- [ ] 🚀 **500 Tools** — full category parity with major competitors, niche tool coverage (resume/career, teacher, freelancer workflows)
- [ ] 🚀 **AI Features** — AI-assisted tool suggestions, smart file processing, natural-language tool search
- [ ] 🚀 **Public API** — documented REST API with API keys and SDKs for select tools (PDF, image, text processing)
- [ ] 🚀 **Premium Tier** — optional higher usage limits and priority support, while core tools stay free

## This List's Roadmap

- [x] ✅ Initial launch with 8 category sections and core contributor docs
- [ ] 🚀 Add a `TOOLS.md` with the complete, auto-sortable table of all 200+ tools (beyond the README's curated examples)
- [ ] 🚀 Add category badges/counts that sync with the live site
- [ ] 🚀 Translate the README into 2–3 additional languages
- [ ] 🚀 Add a lightweight GitHub Action to check for broken links on a schedule
- [ ] 🚀 Cross-link every entry to its matching blog guide, where one exists

## How This Roadmap Changes

Roadmap items move from 🚀 to ✅ as they ship on the live site or in this repo. Suggestions for new roadmap items are welcome via a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) issue.
