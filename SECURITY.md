# Security Policy

## Scope

This repository is a curated markdown list — it contains no executable code, dependencies, or build pipeline. The practical security surface here is limited to:

- Malicious or deceptive links being added to the list
- Compromise of the GitHub repository itself (unauthorized commits/access)

For security issues related to the **OnlineToolkitHub website or tools** (onlinetoolkithub.com), see [Reporting a Website Vulnerability](#reporting-a-website-vulnerability) below — that is a separate codebase from this list.

## Reporting a Link/Content Issue

If you find a link in this list pointing to a malicious, deceptive, or compromised site (including a previously-legitimate tool whose domain has since been taken over), please report it immediately:

1. Open an issue using the **Bug Report** template, or
2. Contact us directly via [onlinetoolkithub.com/contact](https://www.onlinetoolkithub.com/contact)

We will remove or update the affected entry as soon as it's verified, typically within 48 hours.

## Reporting a Website Vulnerability

If you've found a security vulnerability on **onlinetoolkithub.com** itself (XSS, data exposure, authentication bypass, etc.), please **do not open a public GitHub issue**. Instead:

- Email us via the contact form at [onlinetoolkithub.com/contact](https://www.onlinetoolkithub.com/contact), or
- Reach out via WhatsApp: [+91 73034 99330](https://wa.me/917303499330)

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any relevant screenshots, logs, or proof-of-concept code

We ask that you give us a reasonable window to investigate and patch before any public disclosure. We aim to acknowledge reports within 2 business days.

## Supported Versions

This repository does not follow a versioning scheme in the software sense — the `main` branch is always the current, supported state of the list.
