# Support

Need help with something related to this list, or the tools it links to? Here's where to go.

## Questions About This Repository

- **Something in the list is wrong or outdated** → open a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md)
- **You want a tool or category added** → open a [Tool Request](.github/ISSUE_TEMPLATE/tool_request.md)
- **You have an idea to improve the list's structure** → open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)
- **You want to contribute directly** → read [CONTRIBUTING.md](CONTRIBUTING.md)

## Questions About the Tools Themselves

For help using a specific tool on OnlineToolkitHub (not this list):

- Check the tool's own FAQ section on its page at [onlinetoolkithub.com](https://www.onlinetoolkithub.com)
- Visit the general [FAQ page](https://www.onlinetoolkithub.com/faq)
- Reach out via the [contact form](https://www.onlinetoolkithub.com/contact) — replies within 24 hours
- WhatsApp: [+91 73034 99330](https://wa.me/917303499330) — replies within 2 business hours

## Requesting a New Tool on the Platform

If you want an entirely new tool built (not just added to this list), use the [Request a Tool](https://www.onlinetoolkithub.com/request-a-tool) page on the website — the roadmap is shaped directly by user requests.

## Business & Development Inquiries

For custom development work (CRM, websites, backend/API development, integrations), see [Development Services](https://www.onlinetoolkithub.com/services).
